Privacy Policy

Rehfeld Personal Health Dashboard — last updated 20 August 2026.

What this application is

This is a private, single-user application built and operated by Jason Rehfeld for the sole purpose of viewing and analyzing his own Oura Ring data. It is not offered to the public, has no other users, and does not accept registrations.

What data it accesses

Using the Oura API v2 with the operator's own explicit authorization, it reads the operator's Oura data: sleep, readiness, activity, heart rate, heart-rate variability, blood oxygen, stress, workouts, sessions, tags, ring configuration, and basic personal information (age, height, weight, biological sex) used for physiological calculations.

Where the data goes

  • Data is fetched to the operator's personal computer and stored in a local file (~/.config/oura/) on that machine.
  • It is not sold, rented, shared, or transmitted to any advertiser, data broker, analytics service, or other third party.
  • There is no server, no database, and no account system. Nothing is collected from anyone else.
  • Rendered summaries may be published to a private, access-controlled personal web page visible only to the operator.

Retention and deletion

The operator retains the data for as long as it is useful and may delete it at any time by removing the local files and revoking the application's access from the Oura account settings. Revoking access immediately ends all further data collection.

Security

Credentials are stored with owner-only file permissions on an encrypted, password-protected personal computer. They are never committed to source control.

Children

This application is not directed at children and has no users other than its adult operator.
