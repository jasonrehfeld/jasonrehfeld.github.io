Privacy Policy

Rehfeld Home Assistant Integration — last updated 2 October 2026

What this application is

A private, single-user application built and operated by Jason Rehfeld for the sole purpose of connecting his own Google Nest devices to his own self-hosted Home Assistant server. It is not offered to the public, has no other users, and does not accept registrations.

What data it accesses

Using the Google Smart Device Management API and Google Cloud Pub/Sub, with the operator's own explicit authorization, it receives information about the Nest devices the operator chose to share: device status, doorbell and motion/person events, and camera stream and event media for those devices.

Where data goes

Data is delivered only to the operator's Home Assistant server on his home network and to his own phone notifications. It is not sold, shared with, or disclosed to any third party, and it is not used for advertising, profiling, or training any model.

Retention

Event history is kept on the operator's home server for a limited period according to his Home Assistant settings and is deleted on the operator's schedule.

Revoking access

Access can be revoked at any time from the operator's Google Account (third-party connections) or the Nest Partner Connections Manager, which stops all data delivery.

Google API Services User Data Policy

This application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Questions can be directed to the operator via the support email shown on the Google consent screen.
